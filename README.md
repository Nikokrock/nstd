## Commit Message convention

The library intends to use the idea of conventional commits from Angular
project. The adopted format is using git trailer format with the key named
kind. The key can have a list of comma separated keywords:

    breaking change: commit introducing a breaking change
    feature: commit introducing a new feature
    fix: commit introducing a fix
    build: update on the build system 
    ci: update on the CI files
    docs: update on the doc
    perf: update that improve the performance
    refactoring: code refactoring
    revert: revert
    style: style adjustment
    test: test update
